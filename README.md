# Aura CBD Paris

Crée un site e-commerce premium spécialisé dans la vente de CBD en France.

L'objectif est de maximiser les conversions avec seulement 5 produits.

Le design doit être inspiré des meilleures marques DTC modernes : Apple, Yzy, Represent, Cole Buxton, Gymshark et des restaurants modernes comme Bolkiri.
